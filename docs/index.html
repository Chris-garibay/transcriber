Opening it the first time

These builds are not code-signed. Signing needs paid developer accounts from Apple and Microsoft, so your OS will warn you on first launch. The steps below are the standard way to open unsigned software.

macOS

You will see “Transcriber is damaged” or “cannot be opened”. Drag the app to Applications, then run:

xattr -dr com.apple.quarantine /Applications/Transcriber.app

Windows

SmartScreen shows a blue warning. Click More info, then Run anyway.

How it works

  1. Pick or create a project.
  2. Press Record and talk.
  3. Press Stop. Transcription starts on its own, in the background.
  4. The transcript appears. Copy it, or hand its file path to your coding agent.

Recordings are grouped into projects and stored as ordinary files you can read, search, back up or move somewhere else.

~/Transcriber/Projects/Zeric/Recording 014/
    transcript.txt
    metadata.json

Which means you can just say:

Read: ~/Transcriber/Projects/Zeric/Recording 014/transcript.txt

What happens to the audio

Recordings are working files, not something to accumulate. Once a transcript is made, it is checked before the audio is thrown away — and if anything looks off, the audio stays.

record → save wav → transcribe → verify │ ┌─────────────────────────┴─────────────────────────┐ no issues found anything suspect delete the audio keep the audio mark complete mark needs review

Verification looks for:

CheckCatches
empty_transcriptNothing usable was transcribed
incomplete_coverageTranscript stops well before the audio does
duration_mismatchThe audio file is not the length it should be
suspicious_gapA long stretch of audible sound that produced no text
low_confidenceThe model was unsure of what it heard
repetition_loopThe model got stuck repeating a phrase
non_speech_annotationOutput is mostly [MUSIC PLAYING]-style filler

Audio is never deleted on an error path, and never before a transcript exists on disk. If the app is interrupted mid-recording, the partial audio is repaired and transcribed on the next launch rather than lost.

Building it yourself

git clone https://github.com/Chris-garibay/transcriber
cd transcriber
npm install
npm run fetch:whisper
npm run dev

fetch:whisper compiles whisper.cpp on macOS (needs cmake and the Xcode command line tools) and downloads the prebuilt binary on Windows.
